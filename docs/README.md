# ドキュメントガイド

このファイルは、プロジェクト内ドキュメントの入口です。  
重複記載を避けるため、各テーマの一次情報（Single Source of Truth）を明確にします。

## 運用ルール

- 同じ内容を複数ファイルに重複して書かない
- 詳細は一次情報に集約し、他のファイルはリンク参照にする
- 新しい方針や仕様を追加する場合は、先に一次情報を決めてから記述する
