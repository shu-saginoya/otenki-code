# 地域選択仕様

UIでは、地域を3段階で選ぶ。

## 選択階層

- 地方
- 都道府県
- 市区町村

## ルール

- UIには `class10` と `class15` を出さない
- 予報取得には `class20` を使う
- 選択は「地方 → 都道府県 → 市区町村」の順で行う

## 理由

- 候補を絞り込みやすくする
- 都道府県で分かりやすくする
- 市区町村で正確な天気を取得する

## 保存条件

- 未認証ユーザーは一時選択のみ
- 認証済みユーザーのみ保存可能

## まとめ

- UI: 3段階
- 取得先: `class20`
- 保存: 認証後のみ
