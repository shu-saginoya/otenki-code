# 服装推薦の仕様

## 目的

幼い子どもを育てる家庭の忙しい毎日に、少しでもその負担を軽くすることを目的にする。
天気予報の気温をもとに、着ていく服装やお着替えの準備を素早く判断・準備することをサポートしたい。

- 一目で理解できる（認知負荷を下げる）
- チェックリストのように使える
- 子どもも一緒に見て手伝える

### したいこと

- 最高気温・最低気温の表示
- 日中の服装のリストを表示
- 朝夕の服装のリストを表示
- リストはチェックボックスにする
- 服装のリストはユーザーごとにカスタマイズできる

### 将来的な課題

- 気温だけでなく天気（雨/風/湿度）の影響も考慮する
- 服装の切り替えポイントをカスタマイズできるようにする

## 設計方針

### 服装

箪笥から取り出すことをイメージしてアイテムを設定。
例えば、半袖シャツ・半ズボン・インナー・パンツ・靴下など。
半袖セットなどとまとめてしまうと認知負荷が上がるので、具体的なアイテム単位にする。

- 服装はデフォルト値を用意してカスタムしないでも使えるようにする
- 服装はユーザーごとに増やす（カスタム）できるようにする

### 温度帯

人は約5℃単位で服装を変えるためそれを元に温度帯を定義。

- 4℃以下（とてもさむい）
- 5℃以上9℃以下（さむい）
- 10℃以上14℃以下（すこしさむい）
- 15℃以上19℃以下（すずしい）
- 20℃以上24℃以下（あたたかい）
- 25℃以上29℃以下（あつい）
- 30℃以上34℃以下（とてもあつい）
- 35℃以上（きけんなあつさ）

### 日中と朝夕

日中の服装と朝夕の登下園（登下校）では、気温も服装も変わるため2軸に分けて表示する。
ただし、朝夕は日中の服装の上から着るコートや、帽子などを想定していて、日中の服装との差分を表現する

- 日中は最高気温をもとに算出（半袖シャツ・半ズボンなど）
- 朝夕は最高・最低気温をもとに算出（薄手のパーカー・帽子など）

### 服装と気温帯の関連付け

日中と朝夕の気温帯に対して、それぞれ気温帯ごとに服装をセットできる。
例えば、日中の20℃以上24℃以下の時に「Tシャツ・半ズボン・インナー・靴下」など。

- 初期状態でもそのまま使える（デフォルトの設定）
- 各ユーザーの個性に合わせて少しずつカスタマイズできる
