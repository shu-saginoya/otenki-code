# 服装推薦仕様

## 目的

- 服装をすぐ判断できるようにする
- 日中と朝夕を分けて見せる
- ユーザーごとに調整できるようにする

## ルール

- 気温帯ごとに服装を決める
- 日中は最高気温を基準にする
- 朝夕は最低気温と最高気温を基準にする
- 服装はアイテム単位で扱う

## 気温帯

- 4℃以下: とてもさむい
- 5〜9℃: さむい
- 10〜14℃: すこしさむい
- 15〜19℃: すずしい
- 20〜24℃: あたたかい
- 25〜29℃: あつい
- 30〜34℃: とてもあつい
- 35℃以上: きけんなあつさ

## 保存条件

- デフォルト服装は常に利用できる
- カスタム服装は認証済みユーザーのみ保存可能
- 未認証ユーザーはデフォルト表示のみ
