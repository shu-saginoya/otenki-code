# アプリコンセプト

このドキュメントは、プロジェクト全体の目的と条件の一次情報です。

## 目的

気象庁APIから取得した予報をもとに、子どもの服装準備を素早く判断できるようにする。

- 忙しい朝や前夜の準備時間を短縮する
- 認知負荷を下げ、家族で確認しやすくする
- 天気確認という作業を継続しやすくする

## ターゲットユーザー

- 保育園・幼稚園くらいの子どもがいる家庭
- 毎日の着替え準備を行う保護者
- 日本国内の天気予報を前提に利用するユーザー

## プロダクトコンセプト

アプリを開いたらすぐに天気と服装がわかる、シンプルで速い体験を最優先にする。

- 最小操作で必要情報に到達できること
- 子どもでも理解しやすい見せ方であること
- 迷わせる操作や過剰な設定を増やさないこと

## 想定ユースケース

- 前夜: 翌日の服とお着替えを準備する
- 朝: 直前の予報を確認して最終判断する

## 体験の方向性

- 親しみやすい
- 遊び心がある
- 直感的で迷いにくい

## 命名・表記

- 日本語名: お天気コーデ
- 英語表記: OTENKI CODE
- ドメイン想定: otenki-code
