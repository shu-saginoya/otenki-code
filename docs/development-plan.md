# 開発計画

プロジェクトはフェーズごとに進める。

## 方針

- 仕様が揃ってから実装する
- 1つのフェーズを完了してから次へ進む
- 変更時はドキュメントも更新する

## フェーズ

1. 目的と仕様の固定
2. コア体験の実装
3. 服装推薦の改善
4. ユーザー設定
5. 品質と運用
6. リリース準備

## Phase 1: 目的と仕様の固定

- 目的を整理する
- スコープを決める
- 認証の範囲を決める
- 保存条件を決める
- 主要仕様を文書化する

完了条件:

- 目的が明確
- 保存制限が明確
- 次に何を作るかがわかる

## Phase 2: コア体験の実装

- 地域選択を実装する
- 予報を表示する
- 服装を表示する
- モバイルで使いやすくする

## Phase 3: 服装推薦の改善

- 気温帯を整理する
- 日中と朝夕を分ける
- エッジケースに対応する

## Phase 4: ユーザー設定

- 認証済みユーザー向けに保存する
- カスタム服装を追加できる
- ユーザー設定を復元できる

## Phase 5: 品質と運用

- テストを整備する
- CI を整える
- 監視と運用を整理する

## Phase 6: リリース準備

- 最終確認を行う
- 監視と復旧を整理する
- リリースを行う
