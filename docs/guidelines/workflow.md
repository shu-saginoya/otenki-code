## ブランチ

- `main`: 安定版
- `feature/<topic>`: 機能追加

## PR

- 変更の背景を簡潔に書く
- 何を変えたかを明記する
- 確認方法を書く

## コミット

- `feat:` 機能追加
- `fix:` バグ修正
- `docs:` ドキュメント更新
- `refactor:` リファクタリング
- `chore:` 些細な修正

## レビュー

- 自分で差分を確認する
- 目的外の変更は避ける

## マージ

- 原則、PR で `main` に統合する
