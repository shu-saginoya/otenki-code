## 人間にもAIエージェントにも読みやすく

- 文章は短くシンプルに記述
- 同じ事を分散して書かない

## フロントマター

- マークダウンファイルには共通のフロントマターを記述する
- GoogleのOKFを参考にする
- フロントマターの項目は`type`・`title`・`description`の3つを原則とする

### Typeの一覧

- Index: 目次
- Principles: プロジェクト全体で守る原則
- Specifications: アプリケーションの具体的な仕様
- Guidelines: 開発者が守る実装・運用ルール
- References: データ定義やAPI仕様などの参照情報

## Indexファイル

- `index.md`ファイルにドキュメントの一覧を作成する
- 新しくドキュメントを追加したら`index.md`に必ず追加する
- `[title](URL) - description`という構成で記載する

## 表記ルール

- 日本語とアルファベット・数字の間に、半角スペースを入れない

## 注意

ドキュメントは未完成の状態で開発はスタートしている。
そのため、必要に応じて見直しや改変したり、新しい仕様の追加を柔軟に検討する。
